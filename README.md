# Team Task Manager Frontend

Frontend for a Team Task Manager application built using Next.js and Tailwind CSS.

## Features

- Login / Signup
- JWT Authentication
- Protected Routes
- Dashboard
- Task Management
- Project Management
- Role-Based UI
- Responsive UI

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Axios
- Vercel (Deployment)

---

## Pages

- `/login`
- `/signup`
- `/dashboard`
- `/tasks`
- `/create-project`
- `/create-task`

---

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=your_backend_api_url
```

---

## Installation

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## Deployment

Frontend deployed using Vercel.
